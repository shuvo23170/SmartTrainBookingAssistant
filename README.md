# Smart Train Booking Assistant

A starter Android app for preparing Bangladesh Railway trip details.

## Features
- Enter origin, destination, journey date, preferred train and passenger count.
- Copy trip details to clipboard.
- Open the official Bangladesh Railway e-ticket site in Chrome.

## Build APK with GitHub Actions
1. Upload the contents of this folder to the root of your repository's `main` branch.
2. Open the **Actions** tab.
3. Select **Build Android APK** and run the workflow (or wait for the push-triggered run).
4. Open the completed workflow run and download the `SmartTrainBookingAssistant-debug-apk` artifact.

## Important limitations
This is an assisted prototype, not an automatic booking bot. It does not automate CAPTCHA/OTP, reserve seats, or make payments. Complete all booking steps yourself on the official railway website.
